Giá vốn Spot

Kết nối tài khoản Binance để xem giá vốn trung bình và lãi/lỗ từng coin bạn đang giữ.

  1. Trên Binance, mở Tài khoản → Quản lý API → Tạo API.
  2. Chỉ bật Cho phép đọc (Enable Reading). Không bật giao dịch hay rút tiền.
  3. Dán API Key và Secret Key vào bên dưới.

Key lưu trên máy này, không mã hóa trên đĩa, chỉ gửi tới api.binance.com.
